# FitBharat

Indian weight-loss companion: food tracker, AI food scan, daily desi diet plan, steps and workouts.

## Run locally

**Prerequisites:** Android Studio (or JDK 17+ and the Android SDK), an Android device or emulator.

1. Copy `.env.example` to `.env` and optionally set `GEMINI_API_KEY` (the app works offline without it).
2. Build and install: `./gradlew :app:installDebug`
